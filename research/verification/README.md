# Verification Pass

Adversarial fact-checks of the research spikes. Each file here re-verifies the claims of
one or more spikes against primary sources, with a mandate to REFUTE rather than confirm.

Verification files record verdicts and required corrections. Corrections are then applied
to the source spikes, so a spike file and its verification file should not disagree once
the pass is closed.

| File | Verifies |
|------|----------|
| `v01-identity-vendor-history.md` | Spike 01: ownership, vendor, versions, history |
| `v03-academia-job-market.md` | Spike 03: the UT claim, job numbers, cited reports |
| `v04-v05-resources-licensing.md` | Spikes 04 and 05: resources, licensing, feasibility |
| `v06-rust-wasm-toolchain.md` | Spike 06 and `docs/gotchas-rust-wasm.md`: toolchain versions |
